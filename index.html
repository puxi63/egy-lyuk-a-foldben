Irányítás

Billentyű és egér: WASD járás, egér nézelődés, bal gomb vagy F ásás, jobb gomb vagy Q létra, Szóköz ugrás / mászás, Shift lefelé, E pult.

Kontroller: bal kar járás, jobb kar nézelődés, RT ásás, LT vagy Y létra, A ugrás, LB lefelé, X pult, B vissza. 2. játékos: Start a másik kontrolleren · kiszállás: a Back gomb nyomva tartása.

2. játékos kontroller nélkül: F2 (még egyszer F2: kiszáll). Nyilak járás, I J K L nézelődés, U ásás, O létra, jobb Shift ugrás / mászás, jobb Ctrl lefelé, P pult (nyilak + Enter a menüben). F3: osztás váltása.

Szünet: Esc vagy a kontroller Start (Menu) gombja, mindkét játékosnak közös. M: zene hangereje (100 / 60 / 30 % / ki), Z: következő zene (kontrolleren LB + View); a hangerők, a véletlen sorrend és a nézelődés a Beállításokban. Saját zenék: assets/music, lásd az OLVASSEL-ZENE.txt-t.
